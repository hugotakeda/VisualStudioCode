# ⚙️ Configurações do VS Code

Este repositório contém meu arquivo `settings.json` pessoal para o Visual Studio Code. Ele serve como backup e como uma maneira rápida de sincronizar meu ambiente de desenvolvimento e preferências entre diferentes máquinas.

## 🚀 Como usar

Para aplicar essas configurações à sua própria instância do VS Code, siga estes passos:

1. Clone este repositório ou simplesmente copie o texto bruto do arquivo `settings.json`.
2. Abra o Visual Studio Code.
3. Abra a Paleta de Comandos (`Ctrl+Shift+P` no Windows/Linux ou `Cmd+Shift+P` no macOS).
4. Digite e selecione **Preferences: Open User Settings (JSON)**.
5. Cole o conteúdo no seu arquivo `settings.json` local.
6. Salve o arquivo. As alterações devem ser aplicadas imediatamente!

## 🛠️ O que está incluído

Embora as configurações específicas possam mudar com o tempo, este arquivo geralmente inclui:

*   **Preferências do Editor:** Tamanho da fonte, altura da linha, configuração do minimapa e comportamentos ao salvar.
*   **Regras de Formatação:** Formatadores padrão, configurações de formatação ao salvar e tamanhos de tabulação.
*   **Interface e Temas:** Cores personalizadas da interface (workbench), temas de ícones e visibilidade do layout.
*   **Configurações de Extensões:** Configurações específicas para linting, depuração e destaque de sintaxe.
